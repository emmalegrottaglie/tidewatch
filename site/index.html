Analyzer Tools How it works Source

Post when your crowd is awake.

Pick a community or account and see which hours of the week its posts do best, worked out from its own recent posts. Free, open source, and it runs entirely in your browser.

Platform

Drop an export file here, or

CSV or JSON with one row per post: a date column and at least one number column (likes, comments, shares…). The file is read on your device and never uploaded.

Where to get a file for each platform
Instagram, Facebook
Meta Business Suite → Insights → Content → Export data (CSV).
X / Twitter
Settings → Your account → Download an archive, then drop data/tweets.js. Or the CSV from X analytics if your account has it.
TikTok
TikTok Studio → Analytics → Content → Download data.
LinkedIn
Page or creator analytics → Content → Export. Save the posts sheet as CSV.
YouTube
YouTube Studio → Analytics → Advanced mode → Content → Export (CSV). Use the video publish time column.
Threads, Pinterest, others
Any analytics CSV that lists each post with its publish time works.
Reddit with upvotes
While signed in to Reddit, open reddit.com/r/NAME/top.json?t=year&limit=100, save the page, and drop it here.

Your own accounts too

Drop the analytics export from Instagram, TikTok, X, LinkedIn, Facebook or YouTube to analyze an account no public API reaches.

Tidewatch is open source under the MIT license. Data comes from each platform's public API and stays in your browser.
