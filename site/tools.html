Small tools for writing posts.

Check a post against every platform's limit at once, tag links for your analytics, and restyle text with Unicode letters. Everything runs on this page.

Character counter UTM link builder Font styles

Character counter

Type or paste a post to see how it fits each platform, counted the way that platform counts.

    UTM link builder

    Add campaign tags to a link so your analytics can tell which post sent the visit.

    Font styles

    Bold, italic and other letter styles that paste anywhere. Screen readers may read these letters one by one or skip them, so keep them for short accents, not whole posts.
